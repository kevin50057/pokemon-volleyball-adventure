內容細節見 `TASKS.md` 的 C3-1、EVO-1、META-1、CODE-1。這份寫的是：怎麼驗證的、Fable 5.2 審查出什麼、怎麼處理，還有要你決定的事。

## 一句話
三章都做完了（道館巡禮 → 四天王與秘境 → 華藍洞窟／超夢）。24 隻夥伴都有「進化之力」。另外加了挑戰規則、訓練家手冊、每日遠征、跨輪羈絆等級，讓通關之後還有東西玩。遠征的程式拆成模組，`npm test`／`npm run build` 會擋下 `any` 和強制轉型。**還沒有部署**，也還沒有真人試玩。

## 驗證
- **自動測試**：`npm test` 75 個全過（5 個檔：`rules`、`route`、`db`、`cards`、`meta`）。
  - 規則：心與章節重來、奇遇、收服、三選一、讀檔檢查。
  - 一路打完三章：章節之間心回滿、卡槽 2 → 3 → 4。百變怪因為印章不夠沒收服；幻之間開著、收服夢幻；打倒超夢後通關、蓋印章、手冊解鎖學習裝置。
  - 每一章的岔路、三種語言的文字齊全（每個節點、規則、卡、覺醒、首領階段、目標、挑戰）。
  - 存檔：重整、重複結算、寫到一半當機、舊分頁、壞檔、未來版本、空間不足、章節重來、手冊新目標、每日存檔位跟主線分開、補位造成的覺醒立刻記進圖鑑。
  - 卡牌、羈絆（含學習裝置的備援標籤）、四張卡加學習裝置的所有組合都不超過上限。
  - 重力場、重力崩壞、念力停球的週期，超夢的階段門檻。
  - 親密度、覺醒、章節重來收回覺醒、羈絆等級、進化之石、補位。
  - 六條挑戰規則、手冊與卡池、達人帶（含在道場丟掉）。
  - 幻之間（章節制、一命到底兩種條件）、百變怪門檻、首領階段檢查點、難度。
  - 每日遠征：計畫固定、分數、只記第一次、連續天數、跨日補紀錄、不收服新夥伴、卡池不吃個人解鎖。
- **型別**：`tsc --noEmit` 沒有錯誤；`npm run strict` 通過（整個 `src` 沒有 `any`、`as unknown as`、`as never`、ts-ignore 類註解）。

  - 第三章：百變怪被擋，跳出「只跟帶過三種夥伴通關的訓練家走（0/3）」；岔路⑦三選一、幻之間開著。

## 要你決定的
1. **每日遠征能不能給永久收服？** 現在是不給。改成給的話，新玩家第一天就可能從每日拿到夢幻、超夢。
2. **每日分數**：現在是只記第一次打完。另一個做法是「取最高分」。重整頁面免費重打（不扣心）是既有設計，會讓每日的一命比較沒重量。
3. **首領階段檢查點**：現在重打首領時從上次打到的階段開始、你的血回滿。要不要只用一次，或重打時首領多 1～2 滴血？
4. **手冊獎勵**：要不要每個目標都給東西，例如稱號、明信片的框、圖鑑上的小徽章（都是純外觀）？
5. **達人帶**：卡槽 +1、心上限 −1。章節制下心不值錢，要不要改成「心上限 −1，而且每章開頭少 1 顆心」之類更有代價的？
6. **SPEC 要同步的地方**：
   - 一輪的長度（三章約 25 場比賽）。
   - 百變怪改成「3 隻夥伴的通關印章」。
   - 夢幻改成「沒有倒下過的訓練家」（章節制：沒重來過章；一命到底：沒輸過）。
   - 超夢首領三階段和階段檢查點。
   - 親密度與覺醒、羈絆等級 Lv2／Lv4 的開局加成。
   - 補位獎勵、學習裝置、達人帶、每日遠征的規則。
