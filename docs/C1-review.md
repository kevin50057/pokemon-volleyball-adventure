# 第一章「道館巡禮」｜給評審的說明

分支：`expedition-m2`（M2 短切片之後的提交）。開關預設關閉，網址加 `?exp=1` 才有入口。沒有部署。

**順序說明：** 維護者沒時間試玩，要求先擴建到一定程度再玩，所以這一章是在 M1、M2 都還沒正式評審、也沒有真人試玩的情況下做的。維護者轉貼了一份評審意見，那份意見只看了 `docs/M2-review.md`，沒看程式差異，所以不算 PLAN 要求的獨立正式評審。

## 外部評審意見的處理

| 項目 | 處理 |
|---|---|
| 「能量」改成撲救距離 | 照做，保留。 |
| 隊伍滿了不問要不要換 | 補上了：收服的角色進「後援」，在地圖上隨時可以換進隊伍（見下面）。 |
| 電腦逐站變強、起始 7 隻、首領球速做法 | 維持。 |
| Blocker 1：殺球速度上限 | 加了 `MAX_BALL_SPEED = 30`：卡牌動過球之後一律夾到 30 以內。另外測試列出所有兩張卡、各種上場角色和羈絆的組合，殺球倍率最高 1.15，不會超過上限。**附帶發現：** 遊戲本體自己的角色技能本來就會超過 30（電腦對打實測：喵喵 62、可達鴨 56、快龍 42，都沒開遠征）。那是原本的行為，遠征不去動它，否則開關關閉時就跟 main 不一樣了。 |
| Blocker 2：水窪、強風沒實測 | 加了電腦對電腦的除錯模式（`PVA.expedition.soak(站名)`，不寫存檔），每個有場地規則的站都打完整場，結果見下面。 |
| Polish 1：手機排版 | 用 375×812 走完一整輪。地圖的站名在手機上原本只有約 5px，改成窄螢幕只標目前這一站、字放大。 |

## 這一章新增的內容

- **路線九站**：熱身草原 → 岔路①（雨天池塘／招財巷）→ 林間小徑（奇遇）→ 岔路②（搖籃丘的胖丁／打瞌睡路口的卡比獸）→ 補給營地 → 強風山口 → 岔路③（地底隧道的三地鼠／鏡子屋的魔牆人偶）→ 龍之巢前的營火 → 龍之巢。總共 7 場比賽。
- **奇遇**：三種，由種子決定遇到哪一種。
  - 林間野餐：回 1 心，或二選一拿卡。
  - 路過的訓練家：三選一拿卡。
  - 山間溫泉：回 1 心。
  - 每種都可以直接走；心已滿時，回心的選項會變灰。
- **新場地規則「搖籃曲」**：低重力，有 1 秒預警，搬自冠軍之路。
- **卡牌 12 張**：新增 6 張。新的火、水羈絆：火讓殺球 ×1.05，水讓移動 ×1.05。新增的角色標籤：火伊布和小火龍是火；水伊布、傑尼龜、可達鴨、鯉魚王是水；快龍是風。
- **後援**：隊伍滿了的收服會進後援。先點後援的那隻，再點隊伍裡要換下的那隻；如果換下的是上場的那隻，換上來的就變成上場的。
- **加成顯示**：改成顯示實際生效的倍率，碰到上限會標「（上限）」。原本顯示的是卡片倍率直接相乘，可能比實際生效的高。
- **圖鑑**：這一章收得到 9 隻（多了胖丁、卡比獸、三地鼠、魔牆人偶）。

內容版本改成 `c1-1`，M2 的舊存檔會顯示「不支援」、原檔不動，可以匯出或另存後開新的一輪（瀏覽器實測過）。

## 驗證

| 項目 | 結果 |
|---|---|
| `npm test` | 32 個全過 |
| 開關關閉、開關打開但沒在遠征比賽中 | 跟 main 逐幀比對：一般對戰 5/5、冠軍之路 2/2 一致 |
| 電腦對打：水窪、黃金球、強風、搖籃曲、首領 | 三個上場角色（皮卡丘、傑尼龜、小火龍）× 四個站，加上強風和其他站各一場：全部打完，球沒有飛出場外；比賽中最長連續沒人碰到球的時間是 107 幀（約 4 秒），沒有卡死 |
| 水窪 | 每場彈起 1～2 次 |
| 強風 | 強風山口一場裡，球在空中被風推了 30 次 |
| 黃金球 | 出現 2 分球 |
| 整輪（手機尺寸） | 選夥伴加備援 → 贏 → 岔路 → 奇遇拿卡 → 岔路 → 收服進後援 → 後援換進隊伍 → 補給站 → 菁英 → 岔路 → 營火 → 首領 → 通關明信片 |

電腦對打的勝負偏向左邊，是因為右邊的電腦被逐站的強度設定削弱過，這不代表真人的勝率。

## 還沒驗證

- 真人試玩（完成時間、能不能看懂規則、想不想再玩）。PLAN 對一章的目標是 35～55 分鐘，目前沒有任何計時。
- 真實手機（只用瀏覽器模擬 375×812 看過排版）、Safari。
- 明信片在手機上字很小（它是要存成圖片的，畫面上看起來小）。
- 英文、韓文頁面逐頁的排版。
- 所有數值。
