## C1-S 章節制
- 維護者的決定：失敗的單位改成「章」（Fable 5.2 設計評審的建議），另外有「一命到底」模式。
- 規則：
  - 每章開始時記一份快照：隊伍、後援、擁有和裝備的卡、走過的路。
  - 心用完 → 回到這一章的開頭，用快照還原，心回滿，記一次「重來」。已經入帳的永久收服不收回。
  - 打倒一章的首領：有下一章就從下一章開頭開始，心回滿、記新的快照；沒有就整輪通關。
  - 一命到底：心用完整輪結束（只有這個模式會有「失敗」）。
  - 卡槽隨章設定（目前第一章 2 格，結構上可以 2 → 3 → 4）。
  - 章節重來之後，同一站會重新從第 1 場數起，所以比賽 id 加上重來次數（`warmup#1~r1`），避免跟之前的結算撞號。
- 存檔：一輪的版本升到 2（多了 mode、chapter、chapterRetries、checkpoint）。版本 1 的舊存檔顯示「不支援」，原檔不動，可以匯出或另存後開新的一輪。
- 程式：`src/features/expedition/logic.ts`（applySettlement）、`content.ts`（CHAPTERS）、`types.ts`。
- 驗證：
  - `npm test` 35 個全過，新增四項：章節重來還原快照、一命到底失敗、存檔檢查、重來後比賽 id 不撞號。
  - 瀏覽器：
    - 新開一輪可以選模式。
    - 在岔路連輸三場：回到熱身草原，心回滿，卡和收服的鯉魚王都回到章開始的樣子，畫面寫「重來 1 次」。
    - 重來後再贏熱身，結算正常（`warmup#1~r1`）。
  - 開關關閉、或開關打開但沒在遠征比賽中：跟 main 逐幀比對 9/9 一致。
- 要改的 SPEC 條文（維護者決定後同步）：§1、§2「3 心用完結束該輪」、§3 百變怪與夢幻條件（「完成正式遠征」「零敗」要重新定義）、§5 存檔欄位。

## C1-V 路線變化與跨輪系統（Fable 設計評審的第 4、5 項）
- **岔路由種子抽**：三個岔路的兩個選項是空位，對手從各自的池裡抽，場地規則從「水窪、黃金球、搖籃曲、沒有規則」抽。
  - 同一個岔路的兩個選項，對手不同、規則也不同；同一輪裡對手不會重複出現。
  - 強風留給菁英。
  - 站名用對手取名（例如「回聲洞」「花田」），規則寫在卡上。
  - 程式：`src/features/expedition/route.ts`（`routeOf`、`resolveMatch`），不寫進存檔：同一個種子重算一定一樣。
- **老朋友來幫忙**：已經收服過的對手，打贏後不擲收服、圖鑑不動，直接加入這一輪的隊伍（滿了就進後援）。
- **有代價的奇遇**：
  - 可疑的攤販：付 1 顆心，換一次只有機制卡的三選一；只剩 1 顆心時不能選。
  - 路邊道場：丟掉一張自己的卡，換一次三選一；丟掉的那張不會再出現。
  - 奇遇池變成 5 種。
- **菁英的三選一只給機制卡**（沒有剩的才給一般卡）。
- **難度等級（0～3，效果累加）**：
  - 等級 1：電腦更強。
  - 等級 2：首領多 2 滴血、更早發怒。
  - 等級 3：每章只有 2 顆心。
  - 任何模式通關一次，就開放下一級。
- **通關印章**：用哪隻夥伴通關、在哪個難度，記在圖鑑上（★）；一命到底另外標。
- **存檔**：一輪多了 rank 欄位，內容版本改成 `c1-4`，舊的一輪顯示不支援。profile 加的欄位（rankUnlocked、stamps、ironmanClears）都可以沒有，所以舊的 profile 照樣能讀，收服紀錄不會掉。
- **驗證**：
  - `npm test` 39 個全過。新增的測試：
    - 路線：200 個種子各自固定；同一個岔路兩個選項不同；同一輪對手不重複；路線組合超過 100 種。
    - 老朋友加入、菁英只給機制卡。
    - 難度與印章、等級 3 只有 2 顆心。
    - 攤販和道場（心不夠、沒有卡時都會擋）。
  - 瀏覽器：
    - 難度選單（還沒通關時，等級 1～3 是鎖住的）。
    - 種子抽出的岔路：喵喵配搖籃曲、果然翁配水窪。
    - 鯉魚王以老朋友身分加入。
    - 果然翁收服後進後援。
    - 道場換卡：丟掉的卡不在三選一裡。
  - 開關關閉或打開但沒在遠征比賽中：跟 main 逐幀比對 9/9 一致。
