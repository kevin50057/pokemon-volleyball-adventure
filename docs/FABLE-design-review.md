# Fable 5.2 設計評審｜roguelike 好不好玩（第一章之後）

由 Fable 5.2 在乾淨的上下文做（子代理，只讀不改）。它讀了 SPEC、PLAN、`docs/C1-review.md` 和遠征、技能、冠軍之路的程式。**沒有執行遊戲、沒有跑測試。** 這是設計評審，不是 PLAN 要求的「讀實際 diff 加測試證據」的正式程式評審。下面是重點摘要；行號是評審當時的版本。

## 結論
不建議照原方向直接擴建第二、三章。存檔與結算的骨架扎實，但以 roguelike 的標準，當時的遠征是「冠軍之路＋三個二選一岔路＋感覺不到的數值卡」。

## 會留人的地方（保留）
- 場地規則本身就是玩法改變（有預警、有對策）。
- 角色技能才是真正的構築主軸，選哪隻夥伴比選哪張卡影響大得多。
- 岔路會顯示對手、規則、收服條件：資訊充分的選擇。
- 首領血條和第二階段預告、明信片、只結算一次的存檔。

## Major（摘要）
- M1：卡槽 2 格，但一章最多拿 6 次卡，多數獎勵沒用。
- M2：羈絆是數值，而且 23 隻裡有 13 隻沒有標籤。
- M3：備援夥伴在比賽中沒有作用。
- M4：已解鎖的對手不再加入當輪隊伍，收服迴圈大約兩輪就結束。
- M5：存檔沒有通關紀錄，SPEC 的百變怪、夢幻條件無從判定。
- M6：奇遇沒有代價型的選擇。
- M7：菁英和首領沒有特別獎勵。
- M8：難度固定，前四場的電腦被削弱，重玩時是負擔。
- M9：第一章的長度沒有計時。

## 卡牌提案（16 張，這次先做了 6 張）
做了：聚氣（連段）、後發制人（防反）、二段跳（空戰）、吊球（詭計）、發球上手（節奏）、氣象球（場地共鳴）。
還沒做：講究頭巾、魚躍救球、背水一戰、高點扣殺、假動作、乘勝追擊、學習裝置（備援也算羈絆）、接力棒（比賽中換人）、達人帶（心上限 −1 換卡槽 +1）、護符金幣。

評審建議的機制卡規則，已經照做並寫進 `src/features/expedition/mech.ts` 開頭：
- 觸發條件不用機率。
- 同一次觸球最多一個改球路的效果，依卡的 ID 排序取第一張。
- 一律過球速上限。
- 發動時有場上提示。

## 三小時結構的建議（需要維護者改 SPEC）
1. 失敗的單位改成「章」，不是整輪。每章 40～60 分鐘，章開頭心回滿。
2. 章節存檔點：輸光回到這一章的開頭，帶著上一章結束時的隊伍和卡牌。
3. 卡槽隨章成長：2 → 3 → 4。
4. 路線有變化：岔路的對手和規則由種子抽，奇遇池加到 8～10 個並加入有代價的選項，菁英和首領給不同的獎勵。
5. 難度階梯：通關後開放下一級。
6. 給想要硬核的人另開「一命到底」模式。

要改的 SPEC 條文：§1、§2（3 心用完結束、難度固定、不做局外戰力）、§3（百變怪、夢幻條件）、§4.1（卡槽、機制卡規則、羈絆只算上場角色）、§4.2（跨輪進度計數）、§5（存檔格式要升版）。

## 跨輪（先做最划算的）
難度階梯 → 卡池解鎖 → 每隻夥伴的通關印章 → 輸了也有進度 → 種子分享。不建議永久的數值成長。

## 評審建議的優先順序
1. 做 5～6 張機制卡換掉數值卡（**這次做了**）。
2. 用這個版本補做真人試玩。
3. 維護者決定三小時結構，同步修 SPEC。
4. 讓路線有變化。
5. 最小的跨輪系統（同一次存檔格式變更）。
