# 月伊布（新角色規格）

PLAN M5 規定新角色要另外立規格，附精靈圖、電腦 AI、音效、平衡模擬。這份就是。

## 素材
- 精靈圖：維護者提供（一張 JPG，7×4 格，跟水伊布、火伊布、雷伊布同一套格式）。
- 原圖的「透明背景」其實是烤進去的棋盤格，加上半透明的黃色光暈。`scripts/make-umbreon-sheet.py` 依顏色只留月伊布本身（深色身體、黃色光環、紅眼），再縮成 64px 一格。
- 已知小瑕疵：撲救的第二格背上有一小塊淺色殘影。

## 技能：同步＋月環
- **被動・同步**：月伊布被對手弄成麻痺、變慢、顛倒或灼傷時，對手也會中同樣的狀態，時間是一半；對手頭上有月環時是全額。
- **殺球・月環**：月伊布的殺球帶月環。對手用身體接到（不是殺回來），頭上掛月環 1.5 秒；這段時間對手的下一顆殺球球速 ×0.9（只算一次）。
- 數值在 `src/features/abilities/tuning.ts`：`umbreonSyncShare`、`umbreonMarkFrames`、`umbreonMarkSpike`。
- 程式：`src/features/abilities/umbreon.ts`。
- 屬性：惡（新屬性，有自己的擊球特效和音色）。
- 電腦 AI：沒有專屬 AI（技能不需要按鍵），用一般電腦。

## 解鎖
冠軍之路：用水伊布、火伊布或雷伊布任一隻通關拿到獎章，就會解鎖（`src/features/campaign/save.ts` 的 `checkSpecial`）。遠征目前不能帶月伊布（遠征的夥伴只有起始 7 隻和遠征收服的）。

## 驗證
- **平衡**：電腦對電腦，月伊布對其他 23 隻各 30 場、左右各半。
  - 整體勝率 47.7%，得分比例 48.9%，比目標 48～52% 低一點。
  - 對超夢只贏 7%（超夢是冠軍之路的最終首領）。不算超夢的話，勝率約 49.5%。
  - 對其他對手落在 43%～57%。
- **同步**：對皮卡丘打 20000 幀。月伊布被麻痺 62 次，皮卡丘被反彈麻痺 62 次。
- **月環**：同一段裡，月環套到皮卡丘頭上 90 次。
- **逐幀比對**：跟 main 比，一般對戰 7/7、冠軍之路 2/2 一致（開關開、關都是）。
  - 唯一的差別是預期內的：百變怪會變身成名冊裡隨機一隻，月伊布現在也在名冊裡。
- **畫面**：瀏覽器裡看過月伊布上場、月環掛在對手頭上。
