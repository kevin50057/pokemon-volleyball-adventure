## C1-S 章節制
- 維護者的決定：失敗的單位改成「章」（Fable 5.2 設計評審的建議），另外有「一命到底」模式。
- 規則：
  - 每章開始時記一份快照：隊伍、後援、擁有和裝備的卡、走過的路。
  - 心用完 → 回到這一章的開頭，用快照還原，心回滿，記一次「重來」。已經入帳的永久收服不收回。
  - 打倒一章的首領：有下一章就從下一章開頭開始，心回滿、記新的快照；沒有就整輪通關。
  - 一命到底：心用完整輪結束（只有這個模式會有「失敗」）。
  - 卡槽隨章設定（目前第一章 2 格，結構上可以 2 → 3 → 4）。
  - 章節重來之後，同一站會重新從第 1 場數起，所以比賽 id 加上重來次數（`warmup#1~r1`），避免跟之前的結算撞號。
- 存檔：一輪的版本升到 2（多了 mode、chapter、chapterRetries、checkpoint）。版本 1 的舊存檔顯示「不支援」，原檔不動，可以匯出或另存後開新的一輪。
- 程式：`src/features/expedition/logic.ts`（applySettlement）、`content.ts`（CHAPTERS）、`types.ts`。
- 驗證：
  - `npm test` 35 個全過，新增四項：章節重來還原快照、一命到底失敗、存檔檢查、重來後比賽 id 不撞號。
  - 瀏覽器：
    - 新開一輪可以選模式。
    - 在岔路連輸三場：回到熱身草原，心回滿，卡和收服的鯉魚王都回到章開始的樣子，畫面寫「重來 1 次」。
    - 重來後再贏熱身，結算正常（`warmup#1~r1`）。
  - 開關關閉、或開關打開但沒在遠征比賽中：跟 main 逐幀比對 9/9 一致。
- 要改的 SPEC 條文（維護者決定後同步）：§1、§2「3 心用完結束該輪」、§3 百變怪與夢幻條件（「完成正式遠征」「零敗」要重新定義）、§5 存檔欄位。

## C3-1 第三章「華藍洞窟」
- **路線（九站）**：洞口（百變怪）→ 岔路⑥ → 地下水脈（奇遇）→ 岔路⑦（三條，其中一條是藏起來的幻之間）→ 洞窟營地 → 試煉・重力之間（耿鬼，重力場）→ 試煉・停滯之間（月伊布，念力停球）→ 最深處的營火 → 超夢。
- **新場地規則**：重力場（週期變重，先出向下箭頭）、念力停球（紫環收攏時球在空中停 0.8 秒，誰碰到就放開；球太低或太靠近人會「失效」）、重力崩壞（變重和變輕輪流，各自先預告）。
- **超夢首領**：你 5 滴血、超夢 9 滴，三個階段：念力 → 念力停球（剩 6 滴）→ 重力崩壞＋幻影（剩 3 滴）。同一次章節嘗試內，輸掉首領戰會記住打到的最高階段，重打從那裡開始；章節重來、打贏都會清掉；一命到底沒有這個檢查點。
- **收服條件**：
  - 百變怪：圖鑑上要有 3 隻不同夥伴的通關印章，不夠就顯示「還差幾隻」，不算收服失敗、不給保底。
  - 夢幻（幻之間）：章節制是這一輪沒重來過任何一章；一命到底（含每日）是一場都沒輸過；或已經有 3 隻印章、或已經收服過夢幻。不符合時岔路上只看得到剪影和條件。
  - 超夢：打贏必收服。
- **卡槽 4 格**；達人帶再 +1。

## EVO-1 進化之力
- **親密度（這一輪）**：上場贏一場 +1，菁英或首領 +2，滿 6 點就覺醒到這一輪結束。章節重來時跟著快照還原。
- **補位的「親密度 +1」**給隊伍裡第一隻還沒滿的（上場的優先）；都滿了就不會出現。
- **進化之石**（第二、三章的奇遇）：選一隻隊伍裡的夥伴，親密度 +2。
- **覺醒的樣子**：只有鯉魚王是真的進化（用現有的暴鯉龍圖）；其他角色樣子不變，名字加★，腳下有光環，力量是進化後的（雷丘之力…）。不畫任何新的寶可夢圖。
- **24 隻都有**：夢幻、超夢、百變怪只有光環和★，沒有效果；其他 21 隻各自是一個「看得到的條件 → 一個效果」，改的是技能的規則，不是倍率。發動時頭上跳字。效果表在 `content/awaken.ts`、實作在 `match/awaken.ts`、說明文字在 `texts/*` 的 `awakenDesc`。
- **跨輪羈絆等級**：以上場身分的累計勝場，3／8／15／25 勝升到 Lv2～5。Lv2 開局親密度 1、Lv4 開局 2；Lv5 圖鑑金框。
- **演出**：結算後依序播收服、覺醒演出（光柱、光環、閃光、★）；補位或進化之石讓誰覺醒也會播，並立刻記進圖鑑。

## META-1 讓人一直玩的系統
- **挑戰規則**（通關一次後開放，可疊加）：空手（不能裝卡）、單打獨鬥（一隻夥伴、不能換人）、暴風季（沒有規則的一般比賽一律強風）、輕裝（每章卡槽 −1）、強大的首領（+3 血）、隨緣（種子決定夥伴、不帶備援）。每條通關都記在手冊上。
